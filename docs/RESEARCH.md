# Research snapshot — 2026-10-04

LinuxDroid has core process/session/runtime modules, native bridge and a persistent foreground Linux session; its README documents real PTY and ARM64 PRoot execution. LinuxDroid's PRoot fork is the intended dependency.

Official Antigravity CLI headless docs expose stream-json NDJSON, continuous stdin sessions, conversation IDs, --model and --effort. Official auth docs describe local silent keyring auth and remote URL/browser/code auth.
